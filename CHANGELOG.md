# Changelog

All notable changes to this project will be documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Planned

- Custom animation callback support
- Automated tests
- Encoded image or video export
- Improved bitmap validation

## [0.1.0] - 2026-10-02

### Added

- Canvas creation and destruction
- Programmatic rectangle and circle sprites
- Bitmap V5 sprite loading
- Reference-counted sprite ownership checks
- Multiple placements of reusable sprites
- Doubly linked placement stack and layer reordering
- Velocity- and acceleration-based movement
- Transparent-pixel handling and canvas clipping
- Raw ARGB32 frame generation
- Basic and extended example programs
- Portable Makefile and repository documentation
- Bitmap header and read validation for safer input handling
